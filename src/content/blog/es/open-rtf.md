Para abrir un archivo **.rtf** en Windows 11, usa **Microsoft Word de escritorio** o **LibreOffice Writer**, que es gratuito. Microsoft retiró WordPad a partir de Windows 11 24H2. Si el Bloc de notas muestra llaves y barras invertidas, abre el archivo en un editor compatible para ver su formato. [Aviso de retirada de WordPad](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features-resources#wordpad).

## Abrir una copia desde el Explorador

1. Haz una copia del original. Si la extensión está oculta, usa **Ver → Mostrar → Extensiones de nombre de archivo**.
2. Pulsa con el botón derecho sobre la copia y elige **Abrir con**. Si el programa no aparece, ábrelo desde Inicio y usa **Archivo → Abrir**.
3. Antes de editar, revisa los encabezados, las listas, las tablas, las imágenes y el final del documento.

## Elegir el editor según lo que necesites

- **Word de escritorio** abre RTF. Con **Guardar como**, puedes crear una copia en ese mismo formato. [Guía de Microsoft sobre RTF](https://support.microsoft.com/en-us/word/create-or-save-a-document-for-earlier-versions-of-word).
- **LibreOffice Writer** es una alternativa gratuita. Si necesitas conservar el tipo de archivo, selecciona el formato de texto enriquecido al guardar. [Formatos compatibles con LibreOffice](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html).
- **Word para la Web** no abre RTF directamente. Para colaborar desde el navegador, crea primero una copia DOCX en un editor de escritorio y compruébala antes de subirla. [Formatos de Word para la Web](https://support.microsoft.com/en-us/word/differences-between-using-a-document-in-the-browser-and-in-word).

## Revisar la copia antes de enviarla

Cierra la copia y vuelve a abrirla. Comprueba las fuentes, las imágenes, las tablas y los saltos de página. Cuando otra persona use un editor específico, comprueba el archivo en ese programa si puedes. Cambiar la extensión a **.docx** no convierte el archivo. En **Guardar como**, selecciona el formato que quieres obtener.
