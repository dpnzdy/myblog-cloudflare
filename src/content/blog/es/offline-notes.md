Guarda tus notas **fuera de las carpetas sincronizadas** y conserva **una copia en otra unidad**. Usa una sola nota de prueba para verificar tanto el guardado como la restauración.

## Elegir una carpeta local

1. Abre `%USERPROFILE%` en el Explorador y crea una carpeta como `Notas-locales`.
2. En el editor, usa **Guardar como** y comprueba la ruta completa. La carpeta Documentos puede estar sincronizada con OneDrive según tu configuración.
3. Si tu aplicación usa una base de datos, haz la copia con su función de respaldo o exportación. Comprueba si incluye imágenes y grabaciones.

## Probar el acceso sin internet

Guarda la nota, cierra la aplicación y desconecta internet brevemente. Abre el archivo desde el Explorador, añade una línea y guarda. Vuelve a abrir la nota para verificar el cambio. Comprueba también las imágenes o grabaciones que necesites. La instalación y las actualizaciones pueden tener requisitos de conexión distintos.

## Hacer una copia y probar la restauración

Copia la carpeta de notas a una unidad externa, en una carpeta con la fecha. Conserva una copia anterior para recuperar versiones. Copia un archivo de vuelta a una carpeta temporal del PC, ábrelo y revisa el texto y los adjuntos. Expulsa la unidad al terminar. Para las copias periódicas, puedes usar el **Historial de archivos** de Windows y comprobar que incluye tu carpeta. [Guía de Microsoft sobre el Historial de archivos](https://support.microsoft.com/en-au/windows/experience/backup-recovery/backup-and-restore-with-file-history).

## Guardar un archivo local en ZinniaShark Note

Pulsa **Ctrl+S**, elige tu carpeta y guarda la nota como archivo `.adq`. Los elementos multimedia insertados forman parte del archivo. Haz una copia de prueba y ábrela en la aplicación para comprobarla. [Guía oficial de guardado](https://dpnzdy.github.io/ZinniaSharkNote/es/guide.html#save).
