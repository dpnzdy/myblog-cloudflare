Öffnen Sie **.rtf**-Dateien mit **Microsoft Word für den Desktop** oder dem kostenlosen **LibreOffice Writer**. Seit Windows 11 Version 24H2 gehört WordPad nicht mehr zu Windows. Zeigt der Editor geschweifte Klammern und umgekehrte Schrägstriche, benötigen Sie für die formatierte Ansicht ein RTF-fähiges Programm. [Hinweis von Microsoft zur Entfernung von WordPad](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features-resources#wordpad).

## Eine Kopie im Datei-Explorer öffnen

1. Duplizieren Sie die Originaldatei. Wenn die Endung fehlt, aktivieren Sie im Explorer **Ansicht → Anzeigen → Dateinamenerweiterungen**.
2. Klicken Sie mit der rechten Maustaste auf die Kopie und wählen Sie **Öffnen mit**. Fehlt das Programm in der Liste, starten Sie es und wählen Sie **Datei → Öffnen**.
3. Prüfen Sie Überschriften, Listen, Tabellen, Bilder und das Dokumentende, bevor Sie etwas ändern.

## Das passende Programm auswählen

- **Word für den Desktop** öffnet RTF und speichert über **Speichern unter** eine RTF-Kopie. [Microsoft-Anleitung zu RTF](https://support.microsoft.com/en-us/word/create-or-save-a-document-for-earlier-versions-of-word).
- **LibreOffice Writer** ist eine kostenlose Desktop-Alternative. Wählen Sie beim Speichern das Rich-Text-Format, wenn die Datei im RTF-Format bleiben soll. [Dateiformate von LibreOffice](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html).
- **Word für das Web** öffnet RTF-Dateien nicht direkt. Erstellen und prüfen Sie am Desktop eine DOCX-Kopie, bevor Sie diese zur Online-Zusammenarbeit hochladen. [Dateiformate in Word für das Web](https://support.microsoft.com/en-us/word/differences-between-using-a-document-in-the-browser-and-in-word).

## Die gespeicherte Kopie kontrollieren

Schließen und öffnen Sie die neue Datei und vergleichen Sie Schriftarten, Bilder, Tabellen und Seitenumbrüche mit dem Original. Soll die Datei in einer bestimmten Anwendung funktionieren, öffnen Sie die Kopie zusätzlich dort. Die Endung einfach in **.docx** umzubenennen ändert das Format nicht. Wählen Sie bei **Speichern unter** das gewünschte Dateiformat aus.
