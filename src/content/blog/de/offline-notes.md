Speichern Sie Ihre Notizen in einem **Ordner außerhalb der Synchronisierung** und sichern Sie eine **Kopie auf einem separaten Laufwerk**. Probieren Sie den Ablauf mit einer einzelnen Testnotiz aus.

## Einen lokalen Ordner auswählen

1. Öffnen Sie `%USERPROFILE%` im Datei-Explorer und erstellen Sie einen Ordner, etwa `Lokale-Notizen`.
2. Wählen Sie im Editor **Speichern unter**. Prüfen Sie den vollständigen Pfad, denn auch der Ordner Dokumente kann über OneDrive synchronisiert werden.
3. Wenn die App ihre Notizen in einer Datenbank speichert, verwenden Sie ihre Sicherungs- oder Exportfunktion. Prüfen Sie, ob Bilder und Tonaufnahmen dabei enthalten sind.

## Die Notiz ohne Internet erneut öffnen

Speichern und schließen Sie die Testdatei. Trennen Sie kurz die Internetverbindung und öffnen Sie die Datei aus dem Explorer. Ergänzen Sie eine Zeile, speichern Sie und öffnen Sie das Dokument erneut. Prüfen Sie auch, ob Bilder angezeigt und Aufnahmen abgespielt werden. Für Installation und Updates können eigene Verbindungsanforderungen gelten.

## Eine Sicherung anlegen und wiederherstellen

Kopieren Sie den Notizordner auf ein externes Laufwerk in einen neuen Ordner mit Datum. Behalten Sie auch eine ältere Kopie. Kopieren Sie eine gesicherte Datei testweise zurück in einen temporären Ordner auf dem PC und öffnen Sie sie dort. Werfen Sie das Laufwerk danach aus. Für regelmäßige Sicherungen können Sie den Windows-**Dateiversionsverlauf** einrichten und prüfen, ob er Ihren Notizordner erfasst. [Microsoft-Anleitung zum Dateiversionsverlauf](https://support.microsoft.com/en-au/windows/experience/backup-recovery/backup-and-restore-with-file-history).

## Mit ZinniaShark Note lokal speichern

Speichern Sie mit **Strg+S** eine `.adq`-Datei in Ihrem Ordner. Eingefügte Medien sind Teil der Datei. Kopieren Sie die Datei zur Probe und öffnen Sie die Kopie in der App erneut. [Offizielle Anleitung zum Speichern](https://dpnzdy.github.io/ZinniaSharkNote/de/guide.html#save).
