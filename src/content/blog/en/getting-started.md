Create a first note by opening a **new document**, writing a short entry, adding a photo and pressing **Ctrl+S**. Try a simple example: a note about something you learned this week, with one picture to illustrate it.

## Install the app and start a document

Use the [app page](/en/app/) to find the Free and Pro editions on Microsoft Store. After installing, launch ZinniaShark Note and press **Ctrl+N** to open a blank document. If a sample opens on first launch, look through it for ideas and then create a separate tab for your own note.

## Write a few lines and add a picture

Give the entry a title that will make sense a month from now. Write two or three sentences about what happened and what you want to remember. To add a photo, use **Insert** or drag a supported image from File Explorer into the document. Add a short caption to explain why the image is there.

## Save, close and reopen

1. Press **Ctrl+S** and save the note as a file such as `weekly-notes.adq` in a folder you can find.
2. Close the tab, then press **Ctrl+O** and select the file you saved.
3. Check that the text and photo are present. Press **Ctrl+S** again after making further edits.

Inserted media is saved in the `.adq` file. If you copy the file to a backup drive or another PC with the app installed, open the copy and verify that your materials are available. [Official ZinniaShark Note user guide](https://dpnzdy.github.io/ZinniaSharkNote/en/guide.html).
