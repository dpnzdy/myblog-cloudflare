Open a **.rtf** file on Windows 11 with **desktop Microsoft Word** or the free **LibreOffice Writer**. Microsoft removed WordPad starting with Windows 11 version 24H2. If the file shows braces and backslashes in Notepad, use an editor that can interpret RTF to see the formatted document. [Microsoft’s WordPad removal notice](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features-resources#wordpad).

## Open the file from File Explorer

1. Make a copy of the original. If you cannot see the extension, choose **View → Show → File name extensions** in File Explorer.
2. Right-click the copy, choose **Open with**, and select Word or LibreOffice Writer. If the editor is missing from the list, launch it and use **File → Open**.
3. Before editing, check a heading, a list, a table or picture, and the end of the document. These are useful places to spot layout changes or missing material.

## Choose an editor for the job

- **Desktop Microsoft Word** can open an RTF and save a new copy in the same format. Use it if it is already installed and you work primarily with Word documents. [Microsoft’s guide to saving as RTF](https://support.microsoft.com/en-us/word/create-or-save-a-document-for-earlier-versions-of-word).
- **LibreOffice Writer** is a free desktop option. Choose the Rich Text format when saving if someone else still needs an RTF. [LibreOffice format list](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html).
- **Word for the web** cannot open RTF directly. To collaborate in a browser, save a DOCX copy from a desktop editor and check the result before uploading it. [Word for the web file support](https://support.microsoft.com/en-us/word/differences-between-using-a-document-in-the-browser-and-in-word).

## Check the edited copy before sending it

Keep the original. Choose **Save As**, pick the file type the recipient expects, then close and reopen the saved copy. Look for changes in fonts, lists, pictures, table cells and page breaks. If the document has to work in a specific editor on another PC, open the copy there as well.

Renaming the extension from **.rtf** to **.docx** leaves the original format in place. Use **Save As** and explicitly select **Word Document (.docx)** to convert the file.
