Local storage matters because it lets you choose **where your notes live and when a copy leaves your PC**. A file in an unsynced folder can stay on the computer until you deliberately export, share or copy it. That control is useful for notes about family, a private journal or early drafts you are keeping to yourself.

## Check where the file actually lives

On Windows, **Documents** can be backed up to OneDrive. You can see a file in File Explorer and still have an online copy. In OneDrive settings, go to **Sync and backup → Manage backup** to see which folders are included. Check any other sync app you use as well. [Microsoft’s OneDrive folder backup guide](https://support.microsoft.com/en-us/onedrive/back-up-your-folders-with-onedrive)

If a note belongs only on this PC, pick a folder outside those sync locations and check the full path when you save. Saving future edits locally does not remove copies you already uploaded or shared. Review those copies separately if they contain sensitive information.

## Match the protection to the situation

| Situation | What helps |
| --- | --- |
| You want fewer copies outside your control | Save in an unsynced local folder and review what you share or export. |
| Someone might use the same computer | Lock Windows when you step away and use separate Windows accounts where appropriate. Encrypt sensitive note files. |
| The PC could be lost or stolen | Use Windows device encryption where available. Keep the recovery key separately. |
| The drive could fail | Keep a separate backup and try restoring a file before you need it. |

Storage location controls where the file goes. Encryption controls who can read a copy while it is locked. A backup keeps the file recoverable. These choices work together. A synced service can be convenient for collaboration and cross-device access. Check its sharing permissions and recovery options when you choose to use it. [Microsoft’s Windows device encryption guide](https://support.microsoft.com/en-us/windows/security/encryption/device-encryption-in-windows)

In ZinniaShark Note, press **Ctrl+S** and choose an unsynced local folder for an `.adq` file. Close the note and find it in File Explorer. When your notes are sensitive, set a document password and confirm that the saved file asks for it when reopened. Keep a separate copy you know how to restore.

If you are comparing apps, check the product’s privacy policy for your version and edition. Look for what the app stores locally, what it uploads and how support attachments are handled.
