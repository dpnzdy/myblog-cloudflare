A multimedia document combines written context with images, audio or video. For a file you can move between computers, choose an editor that **embeds the media in the document** and check that a saved copy plays on another PC. If readers will open your work in a browser, a linked video or a separate attachment may be a better fit.

## Plan a short document before adding media

Try making a one-page field note about a coastal walk. Give it a title and date, then write two sentences saying what you observed. Each piece of media should help the reader understand something specific.

| Add | What to write beside it |
| --- | --- |
| A photo of the shoreline | A caption locating the tide line and a brief description of what is visible. |
| A ten-second recording | A sentence about the sound, such as wind over the microphone, plus a transcript if someone speaks. |
| A short video of the waves | A pointer to the moment worth watching, such as **0:06, when the water reaches the steps**. |

Use a text heading for each section. Add alternative text for images when the editor supports it and put important observations in the body so the document still makes sense with sound off.

## Build the note in ZinniaShark Note on Windows

1. Press **Ctrl+N** to open a new document. Write the title and the notes first so each attachment has a place.
2. Put the cursor where the photo belongs and use **Insert → Image**. Use **Insert → Audio** and **Insert → Video** for the other sections. You can also drag supported files from File Explorer into the editor.
3. Use **PNG, JPEG or GIF** for images, **MP3** for audio and a supported **MP4** for video. Play the clips inside the document and edit the text beside them. MP4 is a container, so playback can still depend on the file’s codec and the device.
4. Press **Ctrl+S** and save an `.adq` file to a local folder. Inserted media is embedded in the saved document. Use short clips and check the saved size before sending it. [ZinniaShark Note’s guide to inserting media](https://dpnzdy.github.io/ZinniaSharkNote/en/guide.html#media)

## Test the file the reader will receive

Close and reopen the saved document. Check that the photo displays, audio plays and the video can seek to the time you mentioned. For a stronger portability check, copy **just the .adq file** to another supported PC with ZinniaShark Note installed, then repeat the test there.

For a reader who only needs the written summary, a PDF can be a useful companion. A normal print-to-PDF export preserves a static page. Share any required audio or video separately for readers who cannot open the `.adq` file. [Getting started with ZinniaShark Note](/en/blog/getting-started/)
