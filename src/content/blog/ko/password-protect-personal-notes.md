개인 노트를 비밀번호로 보호하려면 **저장된 파일을 암호화하는 편집기**를 사용하세요. 저장한 뒤 노트를 닫고 파일 탐색기에서 같은 파일을 다시 엽니다. 내용을 보기 전에 비밀번호 입력창이 뜨는지 확인하면 사본을 만들 때도 보호가 유지되는지 점검할 수 있습니다.

## 보호하려는 상황에 맞는 방법 고르기

- **잠깐 자리를 비울 때**는 Windows 화면을 잠급니다. 이미 열어 둔 노트를 다른 사람이 바로 읽는 상황을 막을 수 있습니다.
- **PC 분실이나 도난이 걱정될 때**는 지원되는 기기에서 Windows 장치 암호화를 확인합니다. 복구 키는 PC 없이도 접근할 수 있는 안전한 곳에 보관하세요. [Microsoft의 Windows 장치 암호화 안내](https://support.microsoft.com/ko-kr/windows/security/encryption/device-encryption-in-windows)
- **노트 사본을 옮기거나 외장 드라이브에 보관할 때**는 노트 파일 자체를 암호화합니다. 암호화된 파일을 여는 데에는 호환 앱과 비밀번호가 필요합니다.

비밀번호는 다른 곳에서 쓰지 않는 긴 문구로 정하고 비밀번호 관리자처럼 다시 찾을 수 있는 곳에 보관하세요. 중요한 노트에 적용하기 전에 내용이 중요하지 않은 연습용 문서에서 절차를 한 번 따라 해 보세요.

## ZinniaShark Note에서 문서 암호 설정하기

1. 보호할 `.adq` 문서를 엽니다. 새 연습용 문서라면 어떤 파일에 적용되는지 확인할 수 있도록 먼저 로컬 폴더에 저장합니다.
2. **파일 → 현재 문서 암호 설정·변경…**을 선택합니다. 비밀번호와 확인란을 입력하고 **적용하고 저장**을 누릅니다. 이미 저장된 문서는 같은 경로에 기록되며 아직 저장하지 않은 편집 내용도 함께 저장됩니다.
3. 잠금 표시를 확인합니다. 문서를 닫은 다음 같은 파일을 다시 열고, 비밀번호를 입력해 본문과 삽입한 미디어를 확인합니다.

ZinniaShark Note는 저장한 문서 내용과 삽입된 미디어를 함께 암호화합니다. 기존 비밀번호를 변경하려면 현재 비밀번호가 필요합니다. 비밀번호를 잊으면 문서의 암호를 풀 수 없으므로 저장한 비밀번호를 다시 찾을 수 있는지 확인하세요. [ZinniaShark Note 문서 암호 안내](https://dpnzdy.github.io/ZinniaSharkNote/ko/guide.html#password)

## 백업과 내보낸 파일도 확인하기

이전에 만들어 둔 암호 없는 백업본이나 이미 보낸 파일은 기존 상태로 남습니다. 내보내기 결과도 별개의 파일입니다. 예를 들어 암호가 설정된 노트에서 PDF를 내보내도 원본의 비밀번호가 PDF에 적용되지는 않습니다. 보낼 파일을 열어 내용과 보호 여부를 확인하세요.

백업을 점검하려면 **암호 설정 후 저장된** `.adq` 파일을 외장 드라이브에 복사하세요. 사본을 PC의 다른 로컬 폴더로 가져와 열고 비밀번호를 요구하는지 확인합니다. 파일 이름은 탐색기에서 볼 수 있으므로 민감한 내용이나 이름은 제목 대신 본문에 적는 편이 좋습니다. [클라우드 없이 노트를 백업하는 방법](/ko/blog/offline-notes-backup/)
