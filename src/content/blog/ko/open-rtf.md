Windows 11에서 **.rtf** 파일을 열려면 **데스크톱 Microsoft Word**나 무료 **LibreOffice Writer**를 사용하세요. Windows 11 24H2부터 WordPad가 제거되었습니다. 메모장으로 열었을 때 본문 사이에 중괄호나 역슬래시가 보인다면, 원래의 서식과 함께 보려면 RTF를 읽을 수 있는 편집기가 필요합니다. [Microsoft의 WordPad 제거 안내](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features-resources#wordpad)

## 파일 탐색기에서 편집기로 열기

1. 파일 탐색기에서 문서의 복사본을 만들어 둡니다. 확장자가 안 보이면 **보기 → 표시 → 파일 확장명**을 켭니다.
2. 복사한 파일을 마우스 오른쪽 버튼으로 클릭하고 **연결 프로그램**에서 Word 또는 LibreOffice Writer를 선택합니다. 목록에 없으면 설치된 편집기를 실행하고 **파일 → 열기**에서 해당 파일을 선택합니다.
3. 문서를 수정하기 전에 첫 페이지와 끝부분, 굵은 글씨, 목록, 표, 이미지가 예상대로 표시되는지 확인합니다.

## 어떤 앱을 선택할까?

- **Microsoft Word 데스크톱**을 이미 사용 중이면 기존 RTF를 열고 **다른 이름으로 저장**에서 RTF 사본을 만들 수 있습니다. [Word의 RTF 저장 안내](https://support.microsoft.com/en-us/word/create-or-save-a-document-for-earlier-versions-of-word)
- **LibreOffice Writer**는 무료로 설치할 수 있는 데스크톱 편집기입니다. 작성과 저장에 RTF 형식이 필요하면 파일 형식 목록에서 리치 텍스트를 선택합니다. [LibreOffice의 지원 형식](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html)
- **브라우저의 Word**는 RTF를 직접 열 수 없습니다. 웹에서 함께 편집해야 한다면 데스크톱 편집기에서 먼저 DOCX 사본을 만들어 서식을 확인하세요. [웹용 Word의 지원 범위](https://support.microsoft.com/en-us/word/differences-between-using-a-document-in-the-browser-and-in-word)

## 수정한 파일을 보내기 전에

상대방이 RTF를 받아야 한다면 **다른 이름으로 저장**에서 .rtf를 선택하세요. 사본을 닫았다가 다시 열어 한글, 표, 페이지 나눔, 이미지가 유지됐는지 확인합니다. 여러 앱에서 같은 문서를 계속 편집해야 한다면 상대방의 편집기에서 열어 보는 것이 가장 확실합니다.

**확장자만 .docx로 바꾸면 형식은 그대로입니다.** 변환하려면 문서를 지원하는 앱에서 열고 다른 이름으로 저장하면서 파일 형식을 직접 선택하세요.
