로컬 저장을 선택하면 **노트를 어디에 두고 언제 PC 밖으로 사본을 보낼지** 직접 정할 수 있습니다. 동기화 대상이 아닌 폴더에 저장한 문서는 직접 내보내거나 공유하기 전까지 PC에 둘 수 있습니다. 개인 일기, 가족 기록, 아직 공개하고 싶지 않은 초안에 유용한 방식입니다.

## 파일이 실제로 어디에 있는지 확인하기

Windows의 **문서** 폴더가 OneDrive 백업 대상일 수 있습니다. 파일 탐색기에 보이는 파일이라도 온라인 사본이 있을 수 있다는 뜻입니다. OneDrive 설정의 **동기화 및 백업 → 백업 관리**에서 대상 폴더를 확인하세요. 다른 동기화 앱을 쓴다면 그 앱의 설정도 확인합니다. [Microsoft의 OneDrive 폴더 백업 안내](https://support.microsoft.com/ko-kr/onedrive/back-up-your-folders-with-onedrive)

한 PC에만 둘 노트는 동기화 대상 밖에 저장하고, 저장 창에 표시되는 전체 경로를 확인합니다. 새 편집본을 로컬에 저장해도 이미 공유하거나 업로드한 사본은 그대로 남습니다. 민감한 내용이 있었다면 공유한 위치도 따로 확인하세요.

## 상황에 맞춰 보호 방법 고르기

| 상황 | 도움이 되는 방법 |
| --- | --- |
| 내가 관리하는 곳에만 사본을 두고 싶다 | 동기화하지 않는 폴더에 저장하고, 공유와 내보내기 대상을 확인합니다. |
| 다른 사람과 PC를 같이 쓴다 | 자리를 비울 때 화면을 잠그고, 필요한 경우 Windows 계정을 분리합니다. 민감한 노트 파일에는 암호를 설정합니다. |
| PC를 잃어버릴 수 있다 | 지원되는 PC에서 Windows 장치 암호화를 사용하고 복구 키를 따로 보관합니다. |
| 드라이브가 고장 날 수 있다 | 별도 장치에 백업하고 파일 하나를 미리 복원해 봅니다. |

저장 위치는 파일이 **어디로 가는지**, 암호화는 잠긴 파일을 **누가 읽을 수 있는지**, 백업은 파일을 잃었을 때 **다시 가져올 수 있는지**를 결정합니다. 여러 기기에서 편집하거나 문서를 함께 써야 한다면 동기화도 편리합니다. 그때는 서비스의 공유 권한과 복원 옵션을 확인하세요. [Microsoft의 Windows 장치 암호화 안내](https://support.microsoft.com/ko-kr/windows/security/encryption/device-encryption-in-windows)

## 테스트 노트 한 개로 확인하기

ZinniaShark Note에서 **Ctrl+S**로 동기화 대상이 아닌 폴더에 `.adq` 파일을 저장해 보세요. 문서를 닫고 탐색기에서 방금 저장한 파일을 찾아봅니다. 민감한 노트에는 문서 암호를 설정하고, 파일을 다시 열어 비밀번호를 요청하는지 확인합니다. 백업 사본도 따로 두고 복원해 보세요.

앱을 고를 때는 사용하는 버전과 에디션의 개인정보처리방침에서 로컬에 보관하는 데이터, 업로드하는 데이터, 고객지원 첨부 파일의 처리 방식을 확인하세요. ZinniaShark Note Windows 1.0 무료판 방침은 로컬 문서 처리와 지원 문의를 구분합니다. Windows의 동기화 설정과 사용자가 직접 공유하는 사본도 각각 확인할 수 있습니다. [ZinniaShark Note Windows 앱 개인정보처리방침](https://dpnzdy.github.io/ZinniaSharkNote/ko/app-privacy.html)

실제 설정과 복원 절차는 [개인 노트에 비밀번호를 설정하는 방법](/ko/blog/password-protect-personal-notes/)과 [클라우드 없이 노트를 백업하는 방법](/ko/blog/offline-notes-backup/)에서 이어서 확인할 수 있습니다.
