Pour ouvrir un fichier **.rtf** sous Windows 11, utilisez **Microsoft Word pour ordinateur** ou **LibreOffice Writer**, qui est gratuit. Microsoft a supprimé WordPad à partir de Windows 11 24H2. Si le Bloc-notes affiche des accolades et des barres obliques inverses, ouvrez le fichier dans un éditeur compatible RTF pour voir sa mise en forme. [Annonce de Microsoft sur WordPad](https://learn.microsoft.com/en-us/windows/whats-new/deprecated-features-resources#wordpad).

## Ouvrir une copie dans l’Explorateur de fichiers

1. Copiez le fichier original. Pour afficher son extension, utilisez **Afficher → Afficher → Extensions de noms de fichiers** dans l’Explorateur.
2. Faites un clic droit sur la copie et choisissez **Ouvrir avec**. Si votre éditeur n’est pas proposé, lancez-le et utilisez **Fichier → Ouvrir**.
3. Avant de modifier le texte, vérifiez les titres, les listes, les tableaux, les images et la fin du document.

## Choisir le bon éditeur

- **Word pour ordinateur** ouvre le RTF. Passez par **Enregistrer sous** pour créer une copie au même format. [Guide Microsoft sur le RTF](https://support.microsoft.com/en-us/word/create-or-save-a-document-for-earlier-versions-of-word).
- **LibreOffice Writer** est une alternative gratuite. Pour conserver le format, sélectionnez le texte enrichi dans la liste des types de fichier. [Formats dans LibreOffice](https://help.libreoffice.org/latest/en-US/text/shared/guide/convertfilters.html).
- **Word pour le web** n’ouvre pas directement les fichiers RTF. Pour collaborer dans un navigateur, créez et vérifiez d’abord une copie DOCX avec un éditeur installé. [Formats dans Word pour le web](https://support.microsoft.com/en-us/word/differences-between-using-a-document-in-the-browser-and-in-word).

## Vérifier la copie avant de l’envoyer

Fermez puis rouvrez la copie et examinez les polices, les images, les tableaux et les sauts de page. Si votre destinataire utilise un éditeur précis, vérifiez le fichier dans cet éditeur. Renommer **.rtf** en **.docx** ne convertit pas le document. Sélectionnez le format de destination dans **Enregistrer sous**.
