새 운영체제를 설치하면 테마와 앱부터 바꾸고 싶지만, 먼저 업데이트와 복구 수단을 준비해야 이후의 시행착오를 줄일 수 있습니다.

## 적용 환경

이 글은 Ubuntu 24.04 LTS 데스크톱을 기준으로 확인했습니다. 다른 버전에서는 설정 이름이나 화면이 다를 수 있습니다.

## 1. 시스템 업데이트

소프트웨어 업데이터를 열어 대기 중인 보안 업데이트를 적용합니다. 터미널을 선호한다면 다음 순서로 패키지 목록과 설치 항목을 갱신합니다.

```bash
sudo apt update
sudo apt upgrade
```

완료 후 재부팅 요청이 있으면 다른 설정을 시작하기 전에 재부팅합니다.

## 2. 추가 드라이버 확인

`소프트웨어 및 업데이트`의 추가 드라이버 탭에서 그래픽 카드와 무선 네트워크 장치용 권장 드라이버를 확인합니다. 현재 장치가 안정적이라면 무조건 변경할 필요는 없습니다.

## 3. 방화벽 활성화

일반 데스크톱에서는 기본 수신 정책을 차단하고 필요한 서비스만 나중에 허용하는 접근이 단순합니다.

```bash
sudo ufw enable
sudo ufw status verbose
```

원격 접속을 사용하는 컴퓨터라면 활성화 전에 SSH 규칙을 먼저 점검해야 합니다.

## 4. 백업 준비

문서와 설정 파일을 저장할 외부 디스크나 신뢰할 수 있는 동기화 위치를 정합니다. 백업 도구에서 첫 백업을 실행한 뒤 실제 파일 하나를 복원해 봅니다.

## 5. 언어와 시간대

한국어 입력기, 키보드 배열, 시간대가 올바른지 확인합니다. 이 설정이 틀리면 파일 시간과 개발 도구 로그를 해석할 때 혼란이 생길 수 있습니다.

## 6. 필요한 앱만 설치

사용 목적이 확실한 앱부터 설치합니다. 동일 앱의 deb, Snap, Flatpak 버전을 동시에 설치하면 업데이트 경로와 파일 권한을 혼동하기 쉽습니다.

## 7. 복구 정보를 기록

디스크 암호화 복구 키, 백업 위치, 설치한 확장 기능을 안전한 장소에 기록합니다. 문제가 생긴 뒤 기억에 의존하는 것보다 짧은 체크리스트가 훨씬 효과적입니다.

## 마무리

업데이트, 드라이버, 방화벽, 백업까지 확인했다면 이제 개발 도구와 개인 설정을 적용할 준비가 된 것입니다.
