# 개발 단계

## 1단계: 범위와 운영 정책 확정

### 작업

- 사이트명, 프로덕션 도메인, 기본 언어 확정
- 독자 페르소나와 콘텐츠 유형 확정
- URL, 카테고리, 태그 규칙 확정
- 광고, 제휴, 협찬 표시 원칙 확정
- 개인정보·쿠키·분석 도구 요구사항 확정
- 성능 예산과 지원 브라우저 확정

### 산출물 및 종료 기준

- 6개 기획 문서 검토 완료
- 미결정 사항과 책임자 기록
- 초기 출시 범위 동결

## 2단계: 프로젝트 기반 구축

### 작업

- Astro와 TypeScript 프로젝트 설정
- 정적 출력과 Cloudflare Pages 빌드 설정
- 코드 품질, 포맷, 타입 검사, 테스트 명령 구성
- 환경 변수와 비밀정보 관리 규칙 구성
- 미리보기 및 프로덕션 배포 흐름 구성

### 종료 기준

- 빈 사이트가 로컬과 Cloudflare Pages 미리보기에서 동일하게 빌드된다.
- 실패한 검사나 빌드가 배포를 차단한다.
- 프로덕션에 비밀정보가 번들되지 않는다.

## 3단계: 콘텐츠 모델과 작성 기반

### 작업

- Content Collections와 스키마 구현
- posts, authors, categories, pages 컬렉션 구성
- Markdown/MDX 렌더링과 허용 컴포넌트 구성
- 이미지 처리, 코드 강조, 목차, 읽기 시간 구현
- 샘플 콘텐츠로 정상·오류 사례 작성

### 종료 기준

- 잘못된 필드와 참조가 빌드 단계에서 구체적인 오류를 낸다.
- 초안과 미래 글이 프로덕션에서 제외된다.
- 일반 글, 튜토리얼, 리뷰 샘플이 정상 렌더링된다.

## 4단계: 디자인 시스템과 공통 레이아웃

### 작업

- 색상, 타이포그래피, 간격, 너비, 반응형 기준 정의
- 헤더, 푸터, 내비게이션, 모바일 메뉴 구현
- 글 카드, 배지, 고지, 버튼, 표, 코드 블록 구현
- 라이트·다크 테마와 포커스 상태 구현
- 광고 자리의 크기와 시각적 구분 정의

### 종료 기준

- 320px부터 대형 화면까지 주요 컴포넌트가 안정적으로 표시된다.
- 키보드 탐색과 확대, 색상 대비의 기본 접근성 검사를 통과한다.
- 광고 로드 전후 레이아웃 이동이 목표 범위 안에 든다.

## 5단계: 페이지와 탐색 구현

### 작업

- 홈, 전체 글, 게시물 상세 구현
- 주제 허브, 카테고리, 태그 페이지 구현
- 소개, 편집 원칙, 광고·제휴 고지, 개인정보, 쿠키, 연락 페이지 구현
- 검색, 페이지네이션, 관련 글, 이전·다음 글 구현
- 404 페이지 구현

### 종료 기준

- 사이트맵의 모든 초기 경로가 생성된다.
- 빈 상태, 긴 제목, 이미지 없음, 많은 태그 등 경계 사례가 깨지지 않는다.
- 모든 내부 링크와 탐색 흐름이 동작한다.

## 6단계: 검색 발견성과 배포 피드

### 작업

- title, description, canonical, robots 메타 구현
- Open Graph와 소셜 이미지 정책 구현
- WebSite, Person, BlogPosting, BreadcrumbList 구조화 데이터 구현
- 조건을 충족하는 리뷰에만 Product와 Review 데이터 구현
- RSS, XML 사이트맵, robots.txt 구현
- 리디렉션과 trailing slash 정책 적용

### 종료 기준

- 메타데이터와 구조화 데이터가 실제 화면 내용과 일치한다.
- 초안, 검색 결과, noindex 페이지가 사이트맵에서 제외된다.
- RSS와 사이트맵이 유효하고 절대 프로덕션 URL을 사용한다.

## 7단계: 수익화와 분석

### 작업

- 광고 제공자와 배치 위치 확정
- 제휴 링크 속성, 추적, 고지 표현 구현
- 분석 이벤트와 검색 성과 측정 구성
- 필요한 경우 동의 관리와 스크립트 로딩 제어 구현
- 광고·분석 차단 환경의 폴백 확인

### 종료 기준

- 동의 전후 스크립트 동작이 정책과 일치한다.
- 광고 또는 추적 실패가 본문 접근을 방해하지 않는다.
- 제휴 글과 링크에 고지가 누락되지 않는다.
- 내부 트래픽과 테스트 이벤트를 구분할 수 있다.

## 8단계: 품질 검증과 출시

### 작업

- 콘텐츠, 기능, 반응형, 접근성, 성능, SEO, 보안 테스트 수행
- Cloudflare Pages 미리보기에서 실제 배포 환경 확인
- 프로덕션 도메인, HTTPS, 리디렉션, 헤더 확인
- 검색 엔진 도구에 사이트맵 제출 준비
- 백업, 롤백, 장애 대응 절차 기록

### 종료 기준

- `06-test-criteria.md`의 필수 출시 기준을 모두 통과한다.
- 치명적·높음 등급 결함이 없다.
- 대표 콘텐츠와 법적·운영 정책 문서가 실제 내용으로 준비된다.
- 배포 뒤 즉시 확인할 점검표와 롤백 방법이 있다.

## 9단계: 출시 후 운영

### 첫 24시간

- 홈, 대표 글, RSS, 사이트맵, 404, 리디렉션 상태 확인
- 분석 수집과 제휴 클릭 이벤트 확인
- Cloudflare 오류 및 빌드 로그 확인

### 첫 4주

- 색인 상태와 검색 쿼리 확인
- Core Web Vitals 실사용 데이터 확인
- 깨진 링크와 오래된 정보 점검
- 광고 위치별 수익과 사용자 경험 비교

### 지속 운영

- Ubuntu, Python, Codex 버전 변경에 따른 글 검토
- 리뷰 가격과 구매 링크의 유효성 확인
- 분기별 개인정보·쿠키·광고 정책 검토
- 오래된 글에 수정일, 변경 이력, 재검증 결과 반영

## 우선순위 원칙

1. 콘텐츠 정확성과 독자 신뢰
2. 접근성과 핵심 기능
3. 검색 발견성과 성능
4. 측정 가능성
5. 수익 최적화

수익 기능은 핵심 콘텐츠와 정책 페이지가 준비된 뒤 활성화한다.
